Everything on this site is generated from the same data our Discord bot uses to run the league. Here's what you can do yourself in Discord — no admin role required.

## Player Commands

<div class="ocl-table-wrap">
<table class="ocl-table">
    <tr>
        <th>Command</th>
        <th>Who can use it</th>
        <th>What it does</th>
    </tr>
    <tr>
        <td><code class="ocl-cmd">/signup battler</code></td>
        <td>Anyone (while signups are open)</td>
        <td>Registers you as a Battler ⚔️ for the current season.</td>
    </tr>
    <tr>
        <td><code class="ocl-cmd">/signup jammer</code></td>
        <td>Anyone</td>
        <td>Registers you as a Jammer 👊 for the current season.</td>
    </tr>
    <tr>
        <td><code class="ocl-cmd">/signup decklist</code></td>
        <td>Battlers</td>
        <td>Submits or updates your decklist (Moxfield or similar URL, optional deck name) for organizer review.</td>
    </tr>
    <tr>
        <td><code class="ocl-cmd">/result</code></td>
        <td>Battlers &amp; Jammers</td>
        <td>Reports a completed match: winner, loser, game record (3-0, 2-1, or Concession), and whether it was a bounty match.</td>
    </tr>
    <tr>
        <td><code class="ocl-cmd">/drop</code></td>
        <td>Battlers &amp; Jammers</td>
        <td>Removes you from the current season if you need to step away. A reason is optional.</td>
    </tr>
</table>
</div>

## Questions?
If a command isn't behaving the way you expect, or you're missing a role you think you should have, post in the bot-bugs channel in discord!
